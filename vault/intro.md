흩어지기 쉬운 배움을 한곳에 모아 두는 **개인 지식 볼트**다. 왼쪽 사이드바의 폴더 트리가 그대로 카테고리다. 나중에 다시 읽었을 때 **무엇을 했고 무엇을 배웠는지** 떠올릴 수 있게 쓰는 것이 목표다.

## 무엇이 담겨 있나

| 카테고리 | 담는 것 |
|---|---|
| 🏢 회사 | 마일스톤별 회고 — 무엇을 고민했고 무엇을 골랐나 |
| 개발노트 | 회사 · 프로젝트를 넘어 다시 쓰는 기술 지식(결함 패턴 · 기법) |
| 🔬 AI R&D | AI 활용 연구 · 사내 교육 · 스터디 |
| 🧪 toyProject | 개인 프로젝트 기록 |
| 📚 TIL | 날짜별 학습 기록 (`YYYY-MM-DD / 내용`) |
| 📖 단어장 | 분야별 용어 정리 — 2026-09 부터 더 늘리지 않는다. 용어 설명은 각 글 안에 쓴다 |

## 어떻게 쌓이나

- 새 기록은 `writedown` 스킬로 **raw(원본, 비공개 보관함) + readable(이 사이트용으로 다시 쓴 글)** 두 벌로 남긴다.
- 회사 작업의 산출물 원문은 이 사이트에 올리지 않는다. 여기에는 다시 쓴 회고만 둔다.
- 서버 · 계정 · 실제 데이터 · 사람 이름처럼 그대로 옮기면 곤란한 것은 빼거나 역할 · 예시 값으로 바꿔 쓴다.
- `vault/` 아래 폴더에 `.md` 를 넣으면 사이드바 트리에 바로 나타난다. 라벨과 순서는 폴더의 `_category_.json` 으로 조정한다.

## 사이트에 있는 것

- 메인 페이지의 금주 · 금일 할 일 위젯
- 로컬 검색(한국어 + 영어)
- Mermaid 다이어그램
- 잠금 카테고리 — 사이드바 아래쪽에 모으고 화면에서만 가린다. 저장소는 공개라 원본 `.md` 는 그대로 보인다.

## 더 해 볼 것

- 최근 노트 위젯, 태그로 교차 탐색
- 읽기 시간 · 마지막 수정일 표시
- 글 사이 관련 노트(백링크) — 연결이 더 쌓이면 그래프 뷰까지
