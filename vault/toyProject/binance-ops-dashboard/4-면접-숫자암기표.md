# 숫자 암기표

> 꼬리질문은 대개 여기서 갈린다. **숫자에는 반드시 근거가 붙는다.**
> 숫자만 외우면 "왜 그 값인가"에서 무너진다. **오른쪽 칸이 본체다.**

---

## 1. 설정값과 그 근거

| 값 | 숫자 | 근거 |
|---|---|---|
| 수집 심볼 | BTCUSDT, ETHUSDT | `SYMBOLS` 환경변수. **코드에 안 박는다** |
| 수집 인터벌 | `1m` 만 | 상위는 SQL 롤업 |
| 최초 백필 | **7일** (`BACKFILL_DAYS`) | 심볼당 약 **10,081봉**. 2심볼 ≈ 2만 행 — 부담 없는 규모 |
| watchdog 임계 | **10초** 무소식 | BTC/ETH 는 aggTrade 가 초당 수 건~수십 건. **10초 침묵은 정상일 수 없다** |
| 재연결 백오프 | **1s → 최대 30s**, jitter | 동시 재연결이 몰리는 것을 흩는다 |
| 무결성 스캔 | **60초** 주기 / **24시간** 창 | 창이 길면 매 분 전체를 훑게 된다 |
| 한 스캔 복구 상한 | 구멍 **20개** | 한 번에 다 메우면 rate limit 을 태운다. 나머지는 다음 주기 |
| REST weight | 분당 **6000**, 소프트 임계 **0.8** | **80% 에서 스스로 늦춘다** |
| REST 페이지 | `limit=1000` | 페이지네이션 루프 |
| 운영 지표 갱신 | **2초** | Data Lag 를 초 단위로 읽으려면 이 정도면 충분 |
| SSE 재연결 안내 | `retry: 3000` (3초) | 브라우저 내장 재연결 |
| SSE 허브 정지 유예 | **10초** | 재연결 3초보다 넉넉히 — 새로고침마다 LISTEN 커넥션을 여닫지 않게 |
| SSE heartbeat | **15초** | 프록시가 유휴 연결을 끊지 않도록 |
| 스트림 멎음 판정 | **8초** 무이벤트 | 지표 push 2초의 **네 배**. heartbeat 는 기준으로 못 쓴다 — SSE **주석 줄**이라 `EventSource` 가 이벤트로 안 준다 |
| 폴백 폴링 | **5초** | 멎었을 때만 돈다. `/api/dashboard` 는 집계를 다 도는 무거운 경로라 상시로 두면 헬스체크를 가볍게 만든 이유와 충돌 |
| DB 풀 | 웹 **5** / 수집기 **10** | 웹은 짧은 조회만 한다 |
| 이동평균 | **MA20** | 기본값 |
| Taker 축 | **±15%p** | ±100%p 면 실제 값이 **중앙 1px 에 뭉갠다** |
| NOTIFY 상한 | **8KB** | 넘으면 알림만 보내고 수신 측이 DB 를 다시 읽는다 |
| 테스트 | **228건** (단위 195 + 통합 33) | 커버리지가 아니라 "깨지면 구멍 나는 지점"만 |
| 변이 검증 | **17건** 전부 잡힘 | 테스트가 실제로 무언가를 지키는지 확인 |
| 색 대비 | 정상 ΔE **33.9** / 색약 **4.1** (최저선 6) | 초록/빨강 단독 인코딩을 버린 근거 |

## 2. 실동작 검증 결과 — 그대로 말할 수 있게

| 시나리오 | 결과 |
|---|---|
| 최초 실행 | `reason=initial` → 심볼당 **10,081봉** 백필 후 WS 연결 |
| 수집기 2분 중단 후 재개 | `reason=restart` → 갭 감지, 복구, **남은 구멍 0** |
| **16시간 정지 후 재시작** | `gapMinutes=663` → 심볼당 **664봉** 자동 복구 |
| **4일 정지 후 재시작** (2026-08-19) | `gapMinutes=5866` → 심볼당 **5,866봉 · 6페이지 · 1.1~1.6초** |
| 연속성 검사 | `gap_count = 0` |
| 커버리지 | **100%** |
| DB 2분 정지 후 복구 | 수집기 **재시작 없음** · 구멍 6봉을 스캐너가 회수 |
| 클린 클론 `docker compose up` | postgres → migrate → collector + web 전 경로 동작 |
| **SSE 가 막히는 환경(터널)** | `stalled` 감지 → 5초 폴링으로 갱신. 배지가 "폴링으로 갱신 중" 표시. 45초 관찰에서 Data Lag·가격·봉 수·차트 축이 전부 갱신됨 |
| 폴백 회귀 검증 | 수정 전 코드로 되돌려(`git stash`) 새 테스트가 **실제로 실패하는지** 확인 |

> **663분·5,866분 건은 만든 시나리오가 아니다.** Docker 를 꺼둔 사이 우연히 생긴
> **진짜 장애**다. 그 점을 말하면 무게가 다르다.

## 3. 데이터 모델 — 테이블은 셋뿐이다

```
klines           PK (symbol, interval, open_time)
                 + source('ws'|'rest'), is_closed, taker_buy_base ...
pipeline_events  connected | disconnected | reconnecting | stale_detected
                 | gap_detected | backfill_started | backfill_completed
                 | rate_limit_throttled | error
collector_state  ws_connected_since, last_message_at, reconnect_count ...
```

`trades` 테이블이 **없는** 것이 aggTrade 미저장(D-08)의 결과다.

`pipeline_events` 가 **그대로 대시보드의 운영 지표**가 된다.
로그를 화면으로 올린 게 아니라, **처음부터 화면이 읽을 것을 이벤트로 기록**했다.

---

## 4. 기동 순서

```
postgres  →  migrate (한 번 돌고 끝)  →  collector + web
```

마이그레이션을 **수집기 부팅의 부수효과로 두지 않은 이유**: 수집기가 못 뜨는 상황
(네트워크 차단·크래시 루프)에서 스키마가 영영 안 생기고 **대시보드도 같이 죽는다.**
두 프로세스가 공통으로 의존하는 단계라 별도 서비스로 뺐다.

> ※ 이건 코드 리뷰에서 지적받아 고친 것이다. **그대로 말해도 된다.**

## 5. 기술 스택 한 줄 근거

| 레이어 | 선택 | 근거 |
|---|---|---|
| 언어 | TypeScript | 프론트·백엔드가 타입과 스키마를 공유 |
| 수집기 | Node.js 독립 워커 | 장기 실행 WS 연결은 웹과 생명주기가 다르다 |
| 웹 | Next.js (App Router) | 서버 컴포넌트로 초기 데이터 + Route Handler 로 API 를 한 프로젝트에서 |
| DB | PostgreSQL 16 | 시계열 UNIQUE 제약 + UPSERT + `date_bin` + 윈도우 함수 |
| ORM | Drizzle | **SQL-first.** `ON CONFLICT` 와 집계 쿼리를 그대로 표현 |
| 차트 | 직접 구현(SVG) | 필요한 게 캔들·라인·다이버징 바 셋뿐. **마크 규격을 쥐는 편이 낫다** |
| 실시간 | LISTEN/NOTIFY → SSE | 인프라를 늘리지 않는다 |
| 패키지 | npm workspaces | 채점자가 `npm install` 만으로 재현. pnpm 은 사전 설치를 요구 |
