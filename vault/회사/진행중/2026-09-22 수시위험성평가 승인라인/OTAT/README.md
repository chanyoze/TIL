# OTAT — 상시·수시위험성평가 표준 승인(SCNT) 자료

상시·수시위험성평가(OTAT)에 표준 승인관리(SCNT)를 도입하고, 타 모듈도 붙일 수 있는 재사용 표준을 수립하기 위한 자료 모음.

폴더는 **작업 성격**으로 나눕니다: 완료·현행(신뢰) / 앞으로 할 것 / 아카이브.
