## 1. 🔴 최우선 — 내용(상세) 그리드 전 컬럼 (배치3b)

내용 그리드의 **거의 모든 컬럼 이름이 바뀌었습니다.** 값이 안 보이면 SQL 별칭↔데이터셋 불일치입니다.

- [ ] 목록에서 평가서 1건 선택 → 내용 그리드에 **모든 컬럼 값이 채워져 표시**된다
  - 대공종/중공종/공종명·공종텍스트, 위치·위치TD, 유해위험요인, 재해형태
  - 작업 시작/종료일, 감소 시작/종료일, 작업인원
  - 빈도(선택/직접입력), 강도(선택/직접입력), 위험성등급, 감소후등급(선택/코드/직접입력)
  - 이전등급, 추가위험, 누적관리여부, 감소확인자, 감소조치자
- [ ] **신규 등록** → 라인추가 → 위 항목 입력 → 저장 → 재조회 시 값 유지
- [ ] **수정** → 값 변경 → 저장 → 재조회 시 반영
- [ ] 라인복사 / 라인삭제
- [ ] 위험성등급 **자동 계산** (빈도 × 강도 → 등급) 동작 ← `RISK_GR_CODE→RISK_GR_NAME` 39곳
- [ ] 옵션 040_002 on/off 에 따라 등급 컬럼(직접입력 ↔ 선택) 전환
- [ ] **필수 입력 검증** — 빈도·강도·위험성등급 비우고 저장 시 해당 셀로 포커스 이동

### 값 전달 경로 (이름이 바뀐 양끝을 같이 봐야 하는 것)
- [ ] **재해사례 가져오기** → 내용 그리드에 유해위험요인·재해형태·위치·작업인원 등이 채워진다
- [ ] **AI작성** 결과 반영 → 공종명·위치·유해위험요인·감소대책·빈도·강도·등급이 채워진다 ← `item.*` 보호분
- [ ] **평가서 가져오기**(이전/타현장/최초정기) → 내용이 복사된다
- [ ] **산정기준** 팝업에서 등급 선택 → 그리드 반영 ← `wdlCdStdd.RISK_GR_NAME → wdlCont.RISK_GR_NAME`

## 2. 검토의견 (배치4)

`CMT_SEQ→OP_SN`, `CMT_CONTENT→OP_CONT` 가 **6개 데이터셋**(본체 공사/안전 + History 2종, 팝업 2종)에 걸쳐 있습니다.

- [ ] 공사팀 검토의견 등록 / 수정 / 삭제
- [ ] 안전팀 검토의견 등록 / 수정 / 삭제
- [ ] 검토의견 **이력(History)** 조회 — 이전 회차 의견이 보인다
- [ ] 승인 팝업에서 공사팀·안전팀 검토의견이 **읽기 전용으로 표시**된다
- [ ] 검토의견 있는 상태에서 승인 진행 (검토의견 검증 로직 통과)

## 4. 조회조건 (배치5)

`COND_MONTH→STD_YM`, `COND_DEGREE→STD_TIME`. **발신 키는 옛 이름 유지**라 팝업 연동을 꼭 봐야 합니다.

- [ ] 연월 변경 → 조회 (기본값이 당월로 세팅되는지도)
- [ ] 회차 콤보 변경 → 조회 (`ALL` 포함, 특별회차 6~15 도)
- [ ] 연월 변경 시 회차 콤보가 그 연월 기준으로 다시 로드된다
- [ ] 조회조건 필수 검증 (연월·구분·회차 비우고 조회)
- [ ] **평가서 가져오기 팝업** → 연월이 넘어간다 ← `COND_MONTH:` 발신키 보존분
- [ ] **제출현황 팝업** → 연월·회차가 넘어간다
- [ ] **리포트 팝업**(제출현황보고) → 조회조건이 넘어간다
