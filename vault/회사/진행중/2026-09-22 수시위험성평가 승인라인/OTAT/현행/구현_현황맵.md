## 2. 빌드/톰캣 트러블슈팅 (실제 겪은 이슈 — 재발 시)

- **`ContextLoaderListener` ClassNotFound** = 배포 `WEB-INF/lib`에 Maven jar 미배포. 근본: `.classpath`의 Maven 컨테이너에 `org.eclipse.jst.component.dependency="/WEB-INF/lib"` 속성 누락 + `${BUILD_TARGET}` 미해결. **해결**: Project > Deployment Assembly에 "Maven Dependencies" 추가 + `BUILD_TARGET=local`(settings.xml 활성 프로파일) + 서버 **Clean → full Publish**.
- **WebSquare Design 뷰에서 탭 그리드 안 보임** = `<w2:content>`에 `style="height:..."` 없어서 접힘. (alwaysDraw 무관.)
- **간헐적 기동 실패**는 대개 WTP publish 타이밍 — Clean+Publish로 안정화.

## 3. 검증 방식

- 회사 Maven 빌드는 에이전트 환경에서 **불가**. → IDE 진단(컴파일) + XML well-formedness(.NET 파서)로 확인, 런타임은 톰캣 재기동.
- **wqxml 스크립트 JS 문법 검증**: `<script>` 블록만 뽑아 `node --check` (node v24 설치돼 있음). XML well-formed 만으로는 JS 오류가 안 잡히므로 wqxml 수정 후 같이 돌린다.
  ```powershell
  $txt=[IO.File]::ReadAllText($p,[Text.Encoding]::UTF8)
  $m=[regex]::Match($txt,'(?s)<script[^>]*>(.*?)</script>')
  [IO.File]::WriteAllText($tmp,$m.Groups[1].Value,(New-Object Text.UTF8Encoding($false))); node --check $tmp
  ```
- ⚠️ **VSCode 의 wqxml 인라인 JS 진단은 스퓨리어스가 섞인다** — `};` 라인에 *"',' expected"* 가 뜨는 식. 단 **문자열 안의 `</br>` 는 진짜로 파서를 깨뜨리므로** 이 파일들에서는 `<br>` 을 쓴다(파일 내 관행도 `<br>`).
- 실동작 필수 확인: `060_003=T` 현장 요청→승인→반려→취소 전경로 + `060_003=F` 현장 회귀 없음 + 목록 승인상태/버튼 사용자별 정확성.
